# Contributing to ToolsViewer Community

This repo is for product feedback — not the private app source.

## Before opening an issue
1. Search existing Issues and Discussions
2. Pick the right template (Tool request / Feature / Bug)

## What helps most
- Clear problem statement
- Links or screenshots
- Browser + device for bugs

## Discussions vs Issues
- **Discussions** — open-ended ideas and questions
- **Issues** — actionable requests we can track

Thank you for helping improve [ToolsViewer](https://www.toolsviewer.com).
